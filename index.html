02/ selected work
  • 01

    Odyssey Design

    A local-first desktop suite: documents, spreadsheets, decks and a multi-track video editor. The timeline compiles the whole project into one ffmpeg filter graph, so there are no intermediate renders. 55 effects, real cross-dissolves, two-pass stabilisation, sidechain audio ducking, ~180 tests that render real video.

    Rust · Tauri · TS →
  • 02

    tokenmeter

    Know where your LLM spend goes. A local proxy that attributes every token to a model, a repo and a branch, then fails CI when a pull request regresses cost. Nothing leaves your network.

    TypeScript · CLI →
  • 03

    chess-engine-1600

    A ~1600 ELO engine with a GUI board, move analysis and recommendations. Built for minimal hardware: no engine binary to install, no server round-trip.

    Engine · GUI →
  • 04

    Nexus

    Single-track video editor, CLI and egui GUI, wrapping ffmpeg for trim, arrange and export. The small predecessor that taught me what Odyssey's timeline needed to become.

    Rust · egui →
